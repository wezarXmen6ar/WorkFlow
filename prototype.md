# Prototype

What the prototype (POC) must show and how it is judged. This is project content; CLAUDE.md only points here.

## Purpose
- The prototype is for the user alone, to decide when to start building the real platform. The user makes that call.

## What success looks like
- It shows the most important elements of the solutions to the problems, and how they connect.
- The workflow is clear and simple. Simplicity is the most important quality.
