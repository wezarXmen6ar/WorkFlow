# Update previews

A visual history of draft updates and their effects.

Each file here is the **preview map** that was shown and confirmed before an update was mirrored from one draft into a later one. It is kept exactly as it was at confirmation time, as a permanent reference — never edited or deleted.

In each preview:
- **Dashed amber border + "NEW"** marks an item the update adds, labelled by type (objective, problem, solution, sub-solution, or feature).
- **Amber lines** mark the new links, distinguishing a new home-parent link from a new "also serves" link, and calling out any link between two items that already existed.
- A written breakdown sits below the map.

Naming: `<date>-<target-draft>-<what-the-update-was>.html`.
