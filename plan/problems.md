# Problems

What stands in the way of the objectives. Only pushed entries live here, and this file changes only through a push (see CLAUDE.md). "Served by" lines are generated by `python workflow/tool.py build`.

**Entry format**

```
## P-001: Title
- Description:
- Serves: O-001
- Also serves: none
- Label: (optional, 2–4 words for the map)
- Status: Open | Solved | Retired
- Served by: (generated)
```

A problem has one home objective ("Serves") and may also serve others ("Also serves"). Only the user marks it Solved, through an Amendment in the draft.
